## PURPOSE
Presentation of the common framework components allowing reusable functions and utility classes that support the CYBNITY application modules based on Vert.x technology stack.

The targeted goals of Vert.x usage is to implement standalone small services in a common way, allowing their isolated and scallable deployment into several types of infrastructures (e.g. based on unique jar execution in JVM; or based on dockerized component representing a business logic scope of a business domain).

Each small system implemented can be coded according to a Boundary Control Entity Architecture approach (see https://bce.design/#benefits for more detail).
